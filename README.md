# About

**RyukOS** is a personal website that i built as my first project on Stardance. I made this website in such a way that it resembles an OS.

* You can open the folders that are present on the site.
* You can use the terminal and the notepad.
* You can leave comments on the comments folder by saving some text on the Notepad.

## How i made it

I built the site using Next.js and Tailwind CSS.
The folders and files are represented using a filesystem object in
TypeScript. I also made the windows draggable so they behave more like actual
desktop windows. For the comments, I used Firebase Firestore. The Notepad sends the  comment to Firestore when the user presses Save, and the Comments
folder reads the saved comments from there.

The site is deployed using Cloudflare Pages.

## Tech

- Next.js
- React
- TypeScript
- Tailwind CSS
- Firebase Firestore
- Cloudflare Pages
